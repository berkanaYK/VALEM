# VALEM proje talimatları

Kaynak ve yayın işlemlerinde [teslimat politikasını](docs/DELIVERY-POLICY.md) uygula. Kullanıcının 30 Eylül 2026 talimatı: kaynak değişiklikleri yerel dallarda tutulur; kaynak push ve PR işlemleri yalnız pazartesi toplu yapılır. APK/AAB GitHub Release yayını ve doğrulanmış sürümlerin VDS dağıtımı her sürümde devam eder. GitHub'a kaynak göndermeyen Git bundle yedeklerini koru. Açık yeni kullanıcı talimatı bu politikayı değiştirebilir.
