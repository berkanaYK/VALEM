# VALEM 3.6.1 — görünüm sürekliliği

- Koyu/açık/sistem seçimi hesabınıza kaydetmeden cihazda saklanır. Menüye, profile veya başka bölüme geçince mod değişmez.
- Demo hesabının ortak sunucu profili cihazın görünümünü sıfırlamaz.
- Profil ekranı sunucudaki eski mod yerine cihazın geçerli modunu gösterir; ekran açılırken seçim olayı görünümü değiştirmez.
- Önceden açılmış ayarlar ekranı geri dönüldüğünde güncel modu gösterir.
- Galeriden arka plan seçimi seçilmiş koyu/açık modu değiştirmez; kontrast seçilen moda göre uygulanır.
- Önceki hesap oturumundan geç gelen ayar yanıtı, çıkıştan veya hesap değişiminden sonra uygulanmaz.
- Profil sayfasının başlığı tamamlandı.

Görünümü Hesabıma Kaydet, tercihi başka/yeni cihazlara taşımak içindir; bu cihazda modun korunması için gerekli değildir. SMS sağlayıcısı ve Play Console kurulumu hâlâ beklenmektedir.

Kaynaklar yerel düzeltme dalı ve Git bundle yedeklerinde tutulur. Kaynak push/PR pazartesi toplu yapılır; APK/AAB Release ve VDS dağıtımı her sürümde sürer. Yayın açıklamasında gerçek kaynak commit bilgisi verilir.
